# organic-traffic-seo-analytics
SEO dashboard tracking keywords, traffic, and ROI using Power BI.

Just built an Organic Traffic & Keyword Performance Dashboard in Power BI!

Here's what this dashboard tracks: 
📌 26K Total Keywords analyzed across multiple intent categories 
📌 1M+ Total Traffic with an Avg. Position of 2.71 
📌 48M Total Search Volume and 1.79% ROI 
📌 Keyword difficulty, position improvement, and CPC breakdown — all in one view

Key insight from the data: 
🔹 82.66% traffic comes from Informational intent keywords 
🔹 "People also ask" position type drives the highest traffic (512K+) 
🔹 Knowledge Panel has the highest ROI % despite lowest traffic

This project helped me understand how SEO data can be made actionable through visual analytics.
